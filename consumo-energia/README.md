## 📌 Sobre o Projeto
Programa em Python desenvolvido para calcular o consumo mensal de energia (em kWh) e estimar o custo mensal de uso de um aparelho doméstico.

---

## 💻 Linguagem
- **Python**

---

## 📐 Fórmula Utilizada
$$consumoMensal = \frac{potencia \times horasDia \times 30}{1000}$$
