## 🎯 Objetivo do Sistema
 Programa em Python desenvolvido para classificar o perfil de consumo de água de diferentes tipos de imóveis (comerciais e residenciais) e emitir alertas educativos aos moradores de uma cidade, auxiliando em uma campanha de conscientização ambiental.

## 🛠️ Tecnologias Utilizadas
* **Linguagem:** Python
* **Controle de Versão:** Git & GitHub
