📊 Pesquisa de Opinião - TudoWeb

📝 Descrição do Projeto

Este é um programa desenvolvido em Python para a empresa de marketing TudoWeb. O objetivo é realizar uma pesquisa de opinião com os clientes para avaliar o grau de satisfação no atendimento.

O sistema coleta os dados dos entrevistados e calcula a quantidade de avaliações positivas e negativas.

⚙️ Funcionalidades

Solicita o Nome, Idade e Opinião de cada entrevistado.

Classifica a opinião baseada em três níveis:

1: EXCELENTE

2: BOM

3: RUIM

Utiliza estruturas de repetição (for) para iterar sobre os entrevistados (configurado para 50 testes, conforme orientação).

Utiliza estruturas de decisão (if/elif/else) para contabilizar as respostas.

Exibe um relatório final com a quantidade total de respostas "EXCELENTE" e "RUIM".

    python app.py
