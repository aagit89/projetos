# Sistema de Desconto Progressivo 🛒

## 📝 Descrição do Projeto

Este é um programa desenvolvido em Python para simular o caixa de uma loja online. Ele aplica um sistema de descontos progressivos baseado no valor total da compra do cliente, utilizando estruturas de decisão lógicas.

### Regras de Negócio:
- Compras **abaixo de R$ 199,99**: Recebem 5% de desconto.
- Compras **entre R$ 200,00 e R$ 299,99**: Recebem 10% de desconto.
- Compras **de R$ 300,00 ou mais**: Recebem 15% de desconto.
